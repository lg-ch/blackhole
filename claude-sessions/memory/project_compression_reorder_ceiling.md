**depth↑(30) + bcp de probes (Fait 10, idée user, MESURÉ 1B, données vérifiées md5) — échoue, mais révèle un BUG de design du multi-probe.** 128t : 20p=0.845 → 40p=0.700 (recall CHUTE quand probes↑). avg_cands EXPLOSE à 3-4 MILLIONS (vs 40k réf) : flipper un niveau PEU PROFOND (petite marge en haut, fréquent à 1B) part dans un sous-arbre énorme → milliers de docs, pas une feuille de 6. top_n=16000 << 4M → garde des docs quasi-aléatoires (votes ≈1) → effondrement. **Diagnostic : le multi-probe "plus petite marge GLOBALE" ne marche qu'avec PEU de probes (256t/10p=0.953, Fait 8, car peu de probes = marges surtout profondes).
